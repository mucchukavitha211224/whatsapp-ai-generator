# 🚀 AI WhatsApp Website Generator

---

# 📌 Introduction

**AI WhatsApp Website Generator** is an automation-based project that creates modern and responsive websites directly through **WhatsApp messages** and **voice commands**.

Users can simply send messages like:

- 📱 “Create restaurant website”
- 🧁 “Build bakery website”
- 👗 “Create fashion website”

The bot automatically:

✅ Understands requirements  
✅ Generates responsive websites  
✅ Adds images and sections  
✅ Deploys website online  
✅ Sends live URL back to WhatsApp  

This project demonstrates **AI integration, automation, frontend development, cloud deployment, and WhatsApp communication** in a single system.

---

# ❗ Problem Statement

Creating websites normally requires:

- Coding knowledge
- Hosting setup
- Design skills
- Technical experience

Many beginners and small businesses cannot create websites quickly.

This project solves that problem by allowing users to generate websites instantly using simple WhatsApp messages and voice commands.
