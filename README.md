# WhatsApp AI Website Generator 🚀

An elegant, beginner-friendly, and highly modular MVP that transforms simple WhatsApp chat descriptions into premium, responsive single-page websites dynamically hosted on **Netlify**!

Powered by **Python Flask**, **Groq AI (Llama 3)**, **Tailwind CSS**, and **Twilio WhatsApp API**.

---

## ✨ Features

- 📱 **WhatsApp Webhook Integration**: Text a simple prompt to a WhatsApp number and get a live URL in seconds.
- 🧠 **AI Requirements Parser**: Extracts business names, templates, color themes, services grids, and contact details from raw text.
- 🎨 **Sleek Dynamic Templates**: Handcrafted premium templates using modern HSL colors, responsive layouts, Inter fonts, and Lucide icons:
  - **Restaurant**: Warm dark-themed culinary menus and booking grids.
  - **Bakery**: Cozy pastel sweet shop catalogs and order panels.
  - **Portfolio**: Sleek dark terminal setups and skill portfolios.
- ⚡ **In-Memory Serverless Deployment**: Compiles templates and deploys them directly to Netlify using in-memory ZIP pipelines (no slow disk reads/writes!).
- 💻 **Visual Developer Console**: Includes a glassmorphic Web UI to monitor system keys, run test prompts, and preview sites instantly in the browser.
- 🛡️ **Zero-Crash Fallbacks**: Built-in keyword classifiers and deployment sandboxes, letting the project run smoothly even without API keys!

---

## 🛠️ Tech Stack

- **Backend**: Python Flask (3.0.3)
- **AI Inference**: Groq API (Llama 3 - 8B Model)
- **Host Engine**: Netlify REST API
- **Gateways**: Twilio WhatsApp Sandbox
- **Styling**: Tailwind CSS & Lucide Icons CDN

## 🚀 Quick Start Setup

Follow these simple steps to run the application locally on **Windows**:

### 1. Clone & Initialize Workspace
Create and activate a Python virtual environment inside the project directory:
```powershell
# Open PowerShell in the workspace root
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Configure Environment Variables
1. Copy `.env.example` and rename it to `.env`:
   ```powershell
   copy .env.example .env
   ```
2. Open `.env` and fill in your developer keys:
   - **Groq API Key**: Get a free key at [console.groq.com](https://console.groq.com/).
   - **Netlify Auth Token**: Generate a Personal Access Token in Netlify under `User Settings > Applications > Personal Access Tokens`.
   - **Twilio Credentials**: Grab your Account SID and Auth Token from your [Twilio Console](https://www.twilio.com/console).

*Note: The application includes smart fallbacks. If any credentials are left as default placeholders, it will cleanly run offline via rule-based parsers and simulated URL links!*

### 3. Launch Flask Server
Start the Flask application:
```powershell
python app.py
```
Open **[http://localhost:5000/](http://localhost:5000/)** in your web browser to enter the **Developer Cockpit Console**!

## 🧪 Testing and Development

### Pathway A: Manual Dashboard Prompter (Easiest)
1. Open the local console at `http://localhost:5000/`.
2. Click any of the **Sample Prompt buttons** (Restaurant, Bakery, Portfolio) to pre-fill the prompter.
3. Click **Generate & Deploy Web Page**.
4. The system will process, generate, and deploy. A beautiful card will appear displaying the template type, dynamic accent color, and a **clickable live Netlify link**!

### Pathway B: Real WhatsApp Sandbox Testing
To wire up the application to receive real messages from WhatsApp:

1. **Fire up Ngrok** to create a secure tunnel to your local server:
   ```bash
   ngrok http 5000
   ```
2. **Copy the HTTPS URL** generated by Ngrok (e.g. `https://abcd-12-34.ngrok-free.app`).
3. **Configure Twilio Webhook**:
   - Go to the **Twilio Console** > **Messaging** > **Try it out** > **Send a WhatsApp Message**.
   - Navigate to the **Sandbox Settings** tab.
   - Paste your Ngrok HTTPS URL into the "When a message comes in" input, adding `/webhook` at the end:
     `https://abcd-12-34.ngrok-free.app/webhook`
   - Set the method to **HTTP POST** and click **Save**.
4. **Send a WhatsApp message** (e.g. *"Build a French sweet bakery called Sugar & Spice. We offer macarons, sourdough bread, and custom wedding cakes. Contact us at bake@sugar.com"*) to your Twilio Sandbox WhatsApp number.
5. You will get an instant confirmation text, followed shortly by a second text containing your **live Netlify website link**!
