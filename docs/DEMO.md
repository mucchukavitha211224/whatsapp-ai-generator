   - Point out how the site previewer automatically loads the dynamic restaurant with authentic menus and imagery!

   - Type: `"Build a cyberpunk neon portfolio for a photographer named Max"` and send.
   - Show how the visual styles, colors, and layout configurations adapt instantly into cybernetic glows and Fira Code fonts.
